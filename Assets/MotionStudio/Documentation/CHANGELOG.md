# Changelog

## 1.0.0

* Motion Item: fade, slide from any side, scale, rotate, color change, text by word, character or line
* Motion Sequence: order, equal-order groups, interval, two spacing modes, reverse play, timeline and editor preview
* Motion Card: line draws out and opens into the card, or the card grows out of another object; changing line color
* Motion Glow: shaped light from any sprite with blur, brightness, moving gradient, color cycling and grow-in; works masked
* Motion Icon Composer: builds an icon or png from pieces (assemble, pixel, slide, dissolve) in many wave patterns
* TextMeshPro adapter (per piece movement) and legacy Text adapter (per piece fade and color)
* One-line code API (`Motion`), AI agent guide, demo builder, package exporter
* Fade time (Fade Duration / Fade Ease) and initial / final color (Color From / Color To, Color Duration, Color Ease) on Motion Item, Motion Card, Motion Glow (tint) and Motion Icon Composer
